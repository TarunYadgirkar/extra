# TruTec Hatch Matching Challenge

Build a model for a real construction-software problem. Tell us what worked, what failed, and what you would try next.

## Release status

**Dataset and starter code are in preparation. The challenge is not open for submissions yet.** This repository is the permanent landing page. The dataset download, exact task specification, evaluation script, and submission email will appear here when the release is ready.

## The problem

Construction drawings use hatch patterns to distinguish surfaces and materials. This challenge will focus on finding matching hatch regions in drawings. The released specification will define the model inputs and expected outputs.

## Round 1 submission

Once the dataset is available, build an approach and email Ryan:

- A link to your code and instructions to reproduce your results.
- Your evaluation results, hardware, runtime, and time spent.
- A short explanation of your approach and experiments.
- A few visual examples of successes and failures.
- What you would improve with more time.

Disclose any pretrained models, external data, and AI tools you use. A clear, reproducible experiment and thoughtful error analysis matter alongside the score.

You can submit your own repository link; a public pull request is not required. Do not post personal application details in issues.

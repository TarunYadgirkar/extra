# Real drawing examples

Open [the gallery](index.html) to explore three real drawings:

- Fine gray crosshatch
- Wave pattern
- Stipple pattern

Each example shows the input query, a reviewed matching region and reviewed nonmatching regions. Use the controls to switch drawings and inspect the crops. The full-resolution original is available beside each drawing.

These are annotations, not predictions. Only the marked regions have been reviewed; everything else remains unknown. A nonmatching example may show a different pattern or a blank region. The query itself is excluded from scoring. The gallery does not claim complete page labels or model performance.

**Ready to participate?** [Get the dataset and submission instructions](https://github.com/TruTec-AI/hatch-matching-challenge). The repository also includes the evaluator for checking your results.
